# 001. パネルの入れ替え操作

- 状態: 決定
- 日付: 2026-09-24
- 関連: `docs/GAME_DESIGN.md` §3「入力」、`docs/ARCHITECTURE.md` §10「入力」

## 背景

共通基盤(`services/input/`)のスワイプは「50px 以上を 500ms 以内」に動かして離したときだけ通知される。
このため、パズル盤面でスワイプを入れ替えに使うと、ゆっくり動かした指では入れ替えが起きない。
また、指を離すまで入れ替えが始まらないため、操作の反応が遅く感じられる。

## 決定

- **速さを問わないドラッグ方式**で入れ替える
  - 指を置いたパネルから一定距離(**仮仕様: パネル幅の 40%**)動いた時点で方向を確定し、**指を離す前に**入れ替えを始める
- 「1回目のタップで選択、2回目のタップで入れ替え」も併用する
- **共通基盤のスワイプ判定(`swipe` イベント)はパズル盤面には使わない**
  - 盤面では `dragstart` / `dragmove` / `dragend` / `tap` / `cancel` を使う
- 実装は **Phase 3b**(パズル表示)で行う

## 影響

- ロジック(`systems/puzzle/`)は入力の方式に依存しない。入力は「位置 a と b の入れ替え」に変換してから `resolveMove(board, a, b, rng)` に渡す
- 方向を確定するしきい値(パネル幅の 40%)は、Phase 3b でデータまたは設定に置く
- 共通基盤の変更は不要
