# 002. GSAP の採用

- 状態: 決定
- 日付: 2026-09-25
- 関連: `docs/ARCHITECTURE.md` §2「技術構成」、`CLAUDE.md` §3-7(依存ライブラリの追加)

## 背景

Phase 3b(パズル表示)で、入れ替え・消去・落下・連鎖・再配置を順に再生する。
再生には、複数のアニメーションの順番の制御、全体の速さの変更(将来の倍速)、即座の完了(回転時・スキップ)が必要になる。
雛形の `docs/ARCHITECTURE.md` では、演出のタイムラインに GSAP を使う方針(導入候補)としていた。

## 決定

- **GSAP(`gsap` パッケージ、3.15 系)を導入する**
- **`presentation/` 層でのみ使う**(`core` / `data` / `systems` からの import は ESLint でエラーになる。`services` / `app` でも使わない)
- 使うのは本体(`gsap`)だけ。プラグインは必要になった時点で、この記録に追記してから使う

## ライセンス(開発者が確認)

- 確認日: 2026-09-25
- 確認した URL: https://gsap.com/standard-license(最終改定 2025年5月30日)
- 要点
  - Web サイト・Web アプリなどでの利用は許可されている(商用も無料。プラグインも含む)
  - 禁止されているのは、コード不要の視覚的なアニメーション作成ツールなど、Webflow と競合する製品での利用のみ
  - GSAP の著作権表記・ブランド表記を消したり書き換えたりしてはいけない
- このゲーム(ブラウザで遊ぶゲーム)での利用は問題ない
- 著作権表記の扱い: ビルド後の成果物に GSAP の著作権表記が残ることを確認する(Phase 3b の作業報告を参照)

## 影響

- 容量: Phase 3b(GSAP 本体と盤面の表示のコード)で、ビルド後の JavaScript が約 92KB(gzip で約 35KB)増えた
- GSAP は自前の requestAnimationFrame で動く(Pixi の ticker とは別)。シーン終了時にタイムラインを必ず止める
- 雛形(alcyon-game-template)にも同じ判断を還元する候補とする
